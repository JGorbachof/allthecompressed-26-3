# AllTheCompressed - Unofficial Port

Compress blocks into nine storage tiers and unpack them when needed.

Original: [Pdiddy973](https://www.curseforge.com/minecraft/mc-mods/allthecompressed) ([source](https://github.com/Pdiddy973/AllTheCompressed), upstream commit 9c29cefc4214779beb8e9c2aa695a0d840939bf6). Maintained independently by Gorbachof.

## Install

Minecraft 26.3, NeoForge 26.3.0.118, Java 25. Place the JAR from [Releases](https://github.com/JGorbachof/allthecompressed-26-3/releases) in the mods folder on client and server.

## Testing

Native server compression, decompression and all eleven fuel component values passed. Optional integrations and data generation remain untested. Client rendering and extended gameplay remain unverified. This is an alpha release.

## Build

Use Java 25 and the included Gradle wrapper: gradlew.bat jar (Windows) or ./gradlew jar (Linux/macOS). The published binary includes the original license and NOTICE; packaging-only additions may differ from the native-tested build hash.
